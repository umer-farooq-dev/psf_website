Guide d'administration du site

Tout ce qui se règle depuis le panneau d'administration : les produits et leurs prix, les demandes de devis, la galerie des réalisations, les coordonnées de la boutique et l'apparence du site. Aucune de ces valeurs n'est figée dans le code — vous pouvez toutes les modifier vous-même.

01

Se connecter à l'administration

Adresse : votre-site.bf/login/admin

Saisissez votre adresse e-mail, votre mot de passe, puis recopiez le code de sécurité affiché à l'écran. Vous arrivez ensuite sur le tableau de bord.

Important

Ne communiquez ce mot de passe à personne. Si vous devez donner un accès à un employé, créez-lui son propre compte plutôt que de partager le vôtre.

02

La règle des prix

C'est le point le plus important du site. Le prix que vous saisissez — ou que vous laissez vide — décide de tout ce que le client voit et peut faire.

Vous saisissez un prix

  • Le prix s'affiche sur le site
  • Le client peut ajouter au panier
  • Il peut aussi commander par WhatsApp

Vous laissez le prix vide

  • Le site affiche « Contactez-nous pour le prix »
  • Le bouton devient « Demander le prix »
  • Le client vous écrit sur WhatsApp
Astuce

Utilisez le prix vide pour tout ce qui se négocie : gros volumes, matériel sur devis, articles dont le prix bouge souvent. Le produit reste visible et référencé, mais la discussion se fait avec vous.

À retenir

Un produit sans prix ne peut pas être mis au panier, même si quelqu'un essaie de contourner le site. C'est volontaire : on ne vend jamais à un prix qui n'a pas été fixé.

03

Ajouter un produit

Menu : Produits → Ajouter un produit
  1. Donnez un nom clair, celui que le client taperait dans la recherche (« Tube PPR 25 mm », pas « Réf. 4412 »).
  2. Choisissez la catégorie. Créez-la d'abord dans Catégories si elle n'existe pas encore.
  3. Ajoutez une photo. Une seule photo nette vaut mieux que trois floues.
  4. Remplissez le texte alternatif de l'image : décrivez ce qu'on voit. C'est ce que lit Google, et ce qu'entendent les personnes malvoyantes.
  5. Saisissez le prix unitaire — ou laissez-le vide pour un prix sur demande (voir la section précédente).
  6. Indiquez la disponibilité : en stock, ou sur commande.
  7. Enregistrez.
Astuce

La description courte apparaît dans les résultats de recherche de Google. Écrivez-y en une phrase ce que c'est et à quoi ça sert.

04

Les demandes de devis

Quand un client remplit le formulaire « Demande de devis » sur le site, sa demande arrive ici — et vous recevez un e-mail.

Menu : Demandes de devis

Les demandes non lues apparaissent en gras avec une pastille rouge, et le nombre s'affiche à côté du menu. Cliquez sur l'œil pour ouvrir une demande.

Traiter une demande

  1. Ouvrez la demande : vous voyez le nom, le téléphone, le type de client, le produit recherché, la quantité et la pièce jointe éventuelle.
  2. Cliquez sur le numéro pour appeler, ou sur Transférer sur WhatsApp pour envoyer le récapitulatif à votre téléphone.
  3. Passez le statut à Contacté une fois le client joint.
  4. Notez ce qui a été convenu dans la note interne — elle n'est jamais visible par le client.
  5. Passez le statut à Clôturé quand l'affaire est terminée.
Astuce

Le bouton Exporter télécharge la liste au format Excel, en respectant le filtre affiché. Pratique pour un suivi mensuel.

05

Nos réalisations

La galerie des chantiers terminés. C'est ce qui rassure un client qui hésite.

Menu : Nos réalisations → Ajouter une réalisation
  1. Titre du chantier : « Installation sanitaire, villa Ouaga 2000 ».
  2. Catégorie : choisissez-en une dans la liste, ou tapez-en une nouvelle.
  3. Photo, lieu et date de réalisation.
  4. Ordre : le plus petit chiffre s'affiche en premier. Mettez 1 sur vos plus belles réalisations.
  5. Laissez Visible sur le site activé, puis enregistrez.
Bon à savoir

Pour retirer temporairement une réalisation, désactivez Visible plutôt que de la supprimer. Vous pourrez la remettre en un clic.

06

Paramètres PSF

Une seule page regroupe tout ce qui est propre à PSF. C'est ici que vous changez le numéro WhatsApp, l'adresse, les horaires et la carte.

Menu : Paramètres PSF
SectionCe que vous y réglez
WhatsApp Le numéro qui reçoit les demandes de prix et les commandes, et le message du bouton flottant.
Modèles de messages Le texte pré-rempli quand un client vous écrit. {product} et {url} sont remplacés automatiquement par le nom du produit et son lien.
Demandes de devis L'e-mail qui reçoit les notifications, le numéro de transfert, et les types de client proposés dans le formulaire.
Moteurs de recherche Autorise ou empêche Google de référencer le site.
Page d'accueil Les boutons sous le diaporama et les blocs affichés (voir section 07).
Page Contact Adresse, numéros de téléphone, horaires d'ouverture et carte Google Maps.
Nos réalisations Les catégories de projets et le nombre de projets par page.
Menus de l'administration Masque les menus dont vous ne vous servez pas, pour alléger l'écran.
Horaires

Laissez la case des horaires vide pour qu'un jour s'affiche automatiquement comme « Fermé ». Ces horaires apparaissent à la fois sur la page Contact, sur la page d'accueil, et dans les résultats Google.

Carte Google Maps

Sur Google Maps : cherchez la boutique, cliquez sur Partager, puis Intégrer une carte, et copiez le code proposé. Collez-le tel quel dans le champ — le site en extrait ce dont il a besoin.

Adresse

L'adresse ne se saisit qu'une seule fois, ici. Elle alimente la page Contact, le bloc de la page d'accueil, le bouton « Obtenir l'itinéraire » et la fiche Google de la boutique.

07

Organiser la page d'accueil

Menu : Paramètres PSF → section Page d'accueil

Les boutons sous le diaporama

Jusqu'à trois boutons, avec le libellé et le lien de votre choix. Le premier est mis en avant. Un bouton dont le libellé ou le lien est vide n'apparaît pas.

Afficher ou masquer un bloc

Chaque bloc de la page d'accueil possède un interrupteur : vente flash, produits en vedette, catégories, marques, « Pourquoi PSF », notre magasin, et les autres. Activer l'interrupteur masque le bloc — rien n'est supprimé, vous pouvez le réafficher à tout moment.

Pourquoi PSF

Le contenu de ce bloc (les icônes et les phrases du type « Livraison rapide ») se modifie dans Pages et médias → Fiabilité de l'entreprise.

08

Logo et couleurs

Menu : Paramètres commerciaux → Configuration du site

Le logo, l'icône de l'onglet et les couleurs du site se règlent ici. La couleur principale s'applique partout d'un coup : boutons, liens, titres, badges.

Astuce

Changez la couleur, enregistrez, puis rechargez la page d'accueil pour voir le résultat. Si rien ne bouge, videz le cache de votre navigateur (Ctrl + F5).

09

Avant la mise en ligne

À faire une seule fois, le jour où le site passe sur son vrai nom de domaine. Certains points demandent l'intervention de votre développeur.

  • Coordonnées vérifiées — numéros de téléphone, e-mail, adresse et horaires relus dans Paramètres PSF.
  • Carte Google Maps renseignée et pointant sur la bonne boutique.
  • Produits en ligne avec photo, catégorie et prix (ou prix laissé vide volontairement).
  • Référencement activé — Paramètres PSF → Moteurs de recherche.
  • Plan du site généré — Paramètres SEO → Plan du site, une fois les produits saisis.
  • Google Search Console — code de vérification collé dans Paramètres SEO → Outils webmaster.
  • Mot de passe administrateur changé pour un mot de passe long et unique.
  • Réglages techniques — APP_DEBUG passé à false et APP_URL mis à jour avec le vrai domaine (à faire par le développeur).
Le point à ne pas oublier

Tant que APP_DEBUG reste activé, des informations techniques internes sont visibles dans le code des pages. Ce réglage doit impérativement être désactivé avant l'ouverture au public.
